# メニュー・設定更新の確認項目

実装：上書き選択の全件適用（1転送内）、名前変更の全選択・入力幅640、主操作のEnterと標準Esc、評価フィルター右寄せ、フォルダー直下の画像キャッシュ削除、ツリー／ファイル／フォルダー別メニュー、左下設定・ヘルプ、上部ごみ箱ボタン削除、現在のツリーノードの展開、閉じ方向プルダウン。

フォルダーキャッシュ削除は現在存在する直下画像のパス・サイズ・更新日時から、現行JPEGのキーを計算して削除する。サブフォルダーは走査しない。元ファイルやDB・評価には書き込まない。移動・変更前の情報から作られた使われなくなったJPEGは、容量整理または全削除で整理する。処理後に現在の一覧を更新して再生成する。

実機チェック（未実施）：
- 複数の同名項目に、スキップ／別名／上書きの各「全てに適用」。次の転送ではリセットされる。
- 名前変更が全選択され、入力欄が広い。Enterで変更、Escで変更せず閉じる。
- 新規作成、削除、上書き、キャッシュ削除の各ダイアログのEnter／Esc。ファイル操作の処理中Escは安全に停止するまで待つ。
- ファイル・フォルダー・ツリーの指定順メニュー。ツリー操作が右側の選択項目に誤適用されない。
- 評価0～5がキーボードと同じ名前変更になる。
- フォルダー単位キャッシュ削除で直下のみ再生成。サブフォルダー、評価、元画像は残る。
- 複数の一覧ウィンドウから設定を開いても、同じ設定ウィンドウが前面に出る。閉じた後は再度開ける。
- 設定のキャッシュ容量は「適用」で保存され、保存失敗時は元に戻る。削除は確認後だけ実行する。処理中は設定ウィンドウを閉じられない。
- 設定からメモ帳ヘルプを開ける。言語は選択時に保存し、再起動後に反映される。マルチディスプレイは「実装予定」、キー設定は追加・編集・削除・適用ができる。
- 再起動して現在のフォルダーまでツリーが展開され、閉じ方向も保持される。

名前変更の幅は狭いウィンドウでは収まるよう制限する。複数選択の評価は従来のキーボード操作と同様、対象外。
