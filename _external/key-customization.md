# キー・マウス操作のカスタマイズ

## 保存と適用

設定の「操作設定 → キー設定」で編集し、上下の「適用」で全ウィンドウへ即反映する。適用前は従来の割り当てを維持する。別の設定項目に移動しても編集内容を保持する。

「初期設定に戻す」は編集内容を初期設定へ戻すだけで、保存には適用が必要。未適用の変更があるときは、設定または最後の一覧ウィンドウを閉じる前に破棄を確認する。キャンセルするとウィンドウと編集内容を保持する。

SQLiteのsettingsテーブルのinput_bindingsに、Version=2と19機能の割り当てをJSONで一括保存する。Version=1の保存済み設定は読み込み時に戻る・進むを補い、従来の「上の階層」の初期値を「戻る」へ移す。変更後の保存は「適用」のときだけ行う。DBスキーマ変更はない。保存成功後だけ共有サービスの割り当てを差し替える。画面ごとのコピーやイベント購読は用いず、各入力時に共通サービスを参照する。同一プロセス内で即反映し、別途起動したプロセスには再起動後に反映する。

読み込み失敗・未対応の形式・重複・不正な割り当ては、保存内容を上書きせず初期設定へ戻して通知する。設定画面から明示的に適用して保存し直せる。保存失敗時は編集内容を保持し、稼働中の割り当てを維持する。

## 対象と入力規則

- 一覧：開く、戻る、進む、上の階層、評価0～5。戻る・進むは画面上部の履歴ボタンと同じ動作。初期値は戻るがBackspace・マウス戻る、進むがマウス進む、上の階層は割り当てなし。開く・評価は右側の一覧で1項目選択時が対象。ツリーへの評価操作等は追加しない。
- 読書：閉じる、右とじ次／前、左とじ次／前、1ページ先／前、1枚／2枚表示。Spaceは右・左それぞれのページ送りに含める。
- とじ方向別の操作は独立。共通の読書操作は両方のとじ方向で有効。
- 一機能に複数登録でき、すべて削除して「割り当てなし」にできる。下部コントロールは本変更の対象外。
- 通常キー1個とCtrl／Shift／Altの組み合わせ。左右の修飾キーは区別せず、修飾キーは完全一致で判定。
- 英数字、F1～F12、Enter、Space、Backspace、Esc、矢印、Home、End、PageUp、PageDown、Insert、Delete、テンキー数字と四則演算・小数点に対応。
- Tab、記号、IME、Windowsキー、修飾キー単独、複数段階のキー操作は非対応。OS用のAlt+F4、Alt+Space、Alt+Esc、Ctrl+Esc系、Ctrl+Alt+Delete等は予約。Alt+TabもTab自体が対象外。
- テンキー数字と上段数字は別。NumLockオフはWindowsが通知する移動キーとして扱い、テンキーEnterは通常Enterと同じ扱い。
- 一覧の固定ショートカット、標準の移動キーとその修飾キー付き操作は予約。読書では一覧の固定キーを別の操作に利用できる。
- 一覧のマウス候補は中クリック・戻る・進む。読書はそれらに左／右クリック・ホイール上下を追加。修飾キー付き、横ホイール、ダブルクリック、長押し、ドラッグのカスタマイズは非対応。
- 一覧のマウス操作による開く・評価は、ポインターが一覧内にあるときの選択済み1項目に対して行う。
- 文字入力欄、選択コントロール、ボタン、設定画面、ダイアログの操作をカスタム入力で奪わない。
- 読書のホイールは従来どおり120単位を1操作として扱う。設定適用時は残りの累積量を次回入力で破棄する。

## 編集UI

機能名、割り当ての一覧、追加ボタンを3列で並べる。キー欄とマウス操作欄は幅340px。追加ボタンまで設定ウィンドウの初期幅に収まるよう、列幅を固定する。マウス操作の削除ボタンはキー操作の削除ボタンと同じ列に置く。編集・削除アイコンは16pxとし、20pxの内容領域を残してボタンの大きさを維持する。キーは鉛筆で編集、マウスは候補一覧から選択し、削除ボタンで個別削除する。キー登録ダイアログではEsc／Enterも入力候補として取得するため、登録／キャンセルは画面のボタンをクリックする。

競合は同時に有効な操作の間だけで判定する。一覧と読書、右とじ専用と左とじ専用の間は同じ入力を許可する。共通の読書操作は両方向の専用操作と競合する。重複先の機能名を該当行に表示し、競合や候補未選択がある間は適用を無効にする。
