# フォーカス・複数ウィンドウの確認

- 親階層への移動（ボタン／Backspace／マウス戻る）では移動元フォルダーを選択してスクロールし、コンテナー生成後にキーボードフォーカスを設定する。絞り込みで対象がない場合は先頭項目。
- その他のフォルダー移動は一覧先頭の項目（フォルダーを含む）。通常更新は選択パスを維持する。空一覧では一覧自体にフォーカスを置く。
- ContentDialogは呼び出したウィンドウのXamlRootを使用し、表示開始とOpened時にそのウィンドウを前面化する。常時最前面や繰り返し前面化は使わない。
- ドロップはデータ取得後にネイティブドラッグのdeferralを終了してから、次の低優先度UIディスパッチで転送・確認を開始する。移動元への完了通知はNoneとし、未完了の転送を成功と報告したり、移動元側に追加削除をさせたりしない。実際の移動・コピーは従来どおりLiliumの操作エンジンが実施する。
