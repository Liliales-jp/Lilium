# Lilium

Windows向けコミックビューアーです。

## できること

### エクスプローラーウィンドウ

アプリケーションを起動するとエクスプローラーウィンドウが開きます。

- フォルダー内のファイル・フォルダーのサムネイル表示
- フォルダーはその中の対応ファイルのサムネイルを表示します。
- 対応ファイル（JPG / PNG / WEBP / GIF / BMP）はサムネイル表示します。Enterまたはダブルクリックでフルスクリーンで閲覧ビューが開きます。

### 閲覧ビュー

- 見開き・一枚表示、右とじ・左とじに対応
 

- PC配下のドライブからたどれるフォルダーツリーとクイックアクセス
- 子フォルダーと画像のサムネイル一覧（JPG / PNG / WEBP / GIF / BMP）
- ZIP・CBZ内の画像・フォルダー・その他のファイルを読み取り専用で表示（表紙・内部画像のサムネイル対応。画像以外のファイルは開けません）
- 通常フォルダー内のPDFを読書画面で閲覧（先頭ページの表紙サムネイル、ページ送り・一枚／二枚表示・とじ方向に対応）。パスワード入力、ZIP内PDF、PDFページ一覧は対象外。
- 名前順／更新日順、サムネイルサイズ、評価、キーワードの絞り込み
- ファイル名・フォルダー名へレーティングタグを付け外し
- 右とじ／左とじ、一枚／二枚／自動判定の全画面ビューワー
- SQLiteによる設定とクイックアクセスの保存
- `%LocalAppData%\Lilium\cache` のディスクサムネイルキャッシュ（最大300×400、JPEG品質70、S/M/L共通）。「キャッシュ設定」で500 MB～5 GBの上限と手動削除。超過時は利用日時順で90％まで自動整理。

## 実行方法

設定は左下の「設定」から専用の2カラムウィンドウで開きます。同じアプリ内では1つだけ表示します。最後の一覧ウィンドウを閉じると設定も閉じます。キャッシュ容量はスライダーで選び「適用」で保存し、全削除は確認後に実行します。表示言語は日本語・英語に対応し、選択時に保存、再起動後に反映します。言語未選択時は起動時に選択画面を表示します。キー設定では対応するキー・マウス操作を複数登録でき、「適用」で全ウィンドウへ即反映します。情報欄から開発バージョンとヘルプを確認できます。

1. Visual Studioで `Lilium.csproj` を開く。
2. NuGetパッケージの復元を許可する。
3. `F5` を押す。

初回の依存パッケージ取得にはインターネット接続が必要です。`Microsoft.Data.Sqlite` を追加しているため、今回の更新後は一度パッケージ復元を行ってください。

## エクスプローラー機能（追加）

- 新規フォルダー：Ctrl+Shift+N。操作の取り消し：Ctrl+Z。
- 全選択：Ctrl+A。選択解除：Esc。更新：F5、またはアドレス欄の右の更新ボタン。
- 現在のフォルダーの外部変更を自動反映。戻る／進む、アドレス補完、最近のフォルダー（30件を保存）。
- 右クリックから別ウィンドウで開く、エクスプローラーで表示。
- ドラッグ＆ドロップ：通常は移動、Ctrl押下中はコピー。ドラッグ中にCtrlを押す／離すと操作が切り替わります。フォルダーのサムネイルまたはツリー上のフォルダーが転送先となり、一覧の余白では現在のフォルダーが転送先です。
- フォルダーを右クリックして貼り付けると、そのフォルダー内へ転送します（ツリーも対応）。右クリックメニューの貼り付けによるコピーのみ、同じフォルダー内でも `名前 (2)` などの別名で複製します。同じ場所へのドラッグ＆ドロップ、切り取りの貼り付け、Ctrl+Vでは何もしません。
- コピー／移動時の件数・転送量表示、キャンセル。同名時はスキップ／別名／上書きを選択。
- サムネイルのツールチップにパス・更新日時・ファイルサイズ・画像寸法を表示。
- 「フォルダー評価」「ファイル評価」を個別に指定できます。各欄は幅160px・左寄せで、「すべて」または星の下限を選択します。クリアでは両方を「すべて」に戻します。
- 検索ボタンの矢印から「サブフォルダーを含めて検索」を選び、キーワードを入力して検索。右隣のクリアでキーワードと評価による絞り込みを解除。

### ファイル操作（2026-09-17）

- コピー・移動・名前変更・新規フォルダー・削除はWindowsのIFileOperationを使用します。全内容ハッシュ照合や独自退避は行いません。
- 正常完了した直前1操作をCtrl+Zで取り消せます。上書きを含む操作、キャンセル・失敗・結果不明の操作はUndo対象外です。コピーのUndoでは毎回確認し、編集・追加を含めコピー先をごみ箱へ移します。
- 上書き前の項目はごみ箱へ移します。ごみ箱を空にするまで容量を使用します。フォルダーの上書きは統合でなく全体置換です。
- ユーザーのキャンセルは「完了済みの項目はそのままです」と案内して終了します。復旧操作は要求しません。
- 処理中のウィンドウ終了は拒否します。自動キャンセル・終了予約はせず、完了を待つか処理ダイアログからキャンセルしてから閉じるよう表示します。
- エラーはその場で、強制終了などで残った未完了記録は次回起動時や次の操作前に通知します。元・先・別名結果を表示し、上書き前の項目をごみ箱へ移した記録またはその可能性も案内します。通知を閉じると通知済みになり、操作を妨げません。自動再実行・削除はしません。
- 読み取れない操作記録は自動隔離して通知します。隔離できない場合は安全のためファイル操作とUndoを停止しますが、画像の閲覧は継続できます。
- 操作記録は `%LocalAppData%\\Lilium\\operations` に保存します。未通知の中断記録を保持し、通知済みの古い記録は次の操作時に整理します。
- 500ms未満の処理は進捗ダイアログを表示しません。処理対象の識別子・ドライブ・リンク・保護領域・衝突の確認と同時実行排他を維持しています。書き込み先はローカルNTFSに限定します。
- 停電・ディスク故障に対してデータ復旧を保証するものではありません。
