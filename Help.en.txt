Lilium Help

The keys and mouse actions below are defaults. Edit supported commands under Settings > Keyboard and select Apply to update all windows immediately. Check that page for your current bindings. Draft changes are inactive until applied.

Library
Normal folder covers use images, ZIP/CBZ covers, or PDF first pages. Search checks the folder itself, then children, then grandchildren. Folders at each depth and files within each folder use natural name order. Search is limited to 256 folders and excludes hidden/system items and links.
Open a PDF to read its pages in the reader. The first page is used as its cover thumbnail. PDFs requiring an opening password, PDFs inside ZIP/CBZ archives, and a PDF page overview are not supported.
Open a ZIP or CBZ to browse its images, folders, and other files. Files that are not supported images are shown but cannot be opened. Use Up, Back, and Forward as you would in a normal folder.
Archive contents are read-only. Copy, move, delete, rating, Undo, and Quick Access do not apply to entries inside an archive. The archive file itself can be managed as a normal file.
Password-protected ZIP and CBZ files are not supported. RAR and 7z are not supported.
Enter / Space: Open the selected item (when exactly one item is selected)
Backspace / Mouse Back: Back in folder history
Mouse Forward: Forward in folder history
Esc: Go up one folder
Ctrl+C / Ctrl+X / Ctrl+V: Copy / Cut / Paste
If exactly one folder is selected, Ctrl+V pastes into it; otherwise, it pastes into the current location.
Even when the folder tree has focus, Ctrl+V uses the selection in the list on the right.
In a text input, Ctrl+V pastes text normally.
F2: Rename
Del: Move to Recycle Bin
Ctrl+Shift+N: New folder
Ctrl+Z: Undo the most recent file operation (operations with overwriting cannot be undone)
Ctrl+A: Select all
F5: Refresh
0–5: Change the selected item's rating (rating information is added to its name)
Ctrl / Shift + click: Select multiple items
Left-click a blank area: Clear selection
Drag: Move within the same drive; copy to another drive. Ctrl + drag: Copy; Shift + drag: Move.
Turn on Always move under Settings > Controls > File operations to move regardless of drive, except while holding Ctrl to copy.

Reader
The reading controls below also work with PDFs. Pages follow the PDF's order; a landscape spread remains one page. PDF editing, text search, and printing are not supported.
The reader opens full screen on the same monitor as the library window that opened it.
Move the pointer into the bottom 10% of the screen to show the controls. Move away from that area and the panel to hide them.
Use the panel to jump to the first or last page, turn pages, close the reader, and change the page mode or binding direction.
Binding changes are saved and also applied to the library window that opened this reader.
Right-to-left: Left-click for the next page, right-click for the previous page
Left-to-right: Right-click for the next page, left-click for the previous page
Mouse wheel down / up: Next / Previous
Esc / Backspace / Mouse Back: Close the reader
Left and right arrows / A and D: Turn pages according to the reading direction
Down arrow / S: One page forward; Up arrow / W: One page back
Space: Next page
1 / 2: Single-page / Two-page display

Dialogs
Enter: Primary action (create, rename, continue, save, etc.)
Esc: Cancel / Close
During an operation, Esc requests cancellation and waits for a safe stop.
When a selection list is open, it handles selection first.

Settings
Open Settings at the bottom left for language, cache settings, and this help.
There is one settings window per running app instance.
Closing the last library window also closes settings. An active cache operation finishes before the app exits.
Select Japanese or English under Display > Language. The selection is saved immediately and takes effect after restarting Lilium. Close all Lilium windows before starting again.
Choose the cache size with the slider and select Apply to save. Cache deletion requires confirmation.
Thumbnails use JPEG quality 70, up to 300 × 400 pixels, shared by S/M/L display sizes.
The size limit is 500 MB–5 GB. When exceeded, the least recently used cache is removed until usage reaches 90% of the limit.
Clear cache on a folder regenerates images directly inside that folder.
Original images, ratings, and settings are not deleted. Images in subfolders are not included.
The current list is refreshed and regenerated; other locations regenerate when opened next.

Preview pane
Use Preview to the right of Recent, separated by a vertical divider, to open or collapse the pane. It shares the thumbnail area's height; drag its border to resize it.
Exactly one selected item is previewed. Clearing selection or selecting multiple items leaves the pane blank.
Folders and ZIP/CBZ files show their direct images. An image starts at the selected page, and a PDF starts at its first page.
The bottom controls turn pages, change single/two-page display and binding direction, and open fullscreen at the current page with the current binding direction. Fullscreen uses its own saved page mode, just as when opening a file by double-clicking.
Clicks and the mouse wheel turn pages within the reading surface. Controls and border dragging do not also turn pages.
Library shortcuts and nonconflicting reader shortcuts work with focus in either the thumbnail list or the preview reading surface. A/D/W/S control the preview with default bindings.
Arrows, Enter, Space and 1/2 give priority to library actions. Up/Down move between thumbnails even from the preview; Shift/Ctrl selection gestures also work. Text inputs and buttons retain their standard keyboard behavior.
All reader-close commands are disabled in preview. Mouse Back also does not navigate folder history within the pane.
Collapse with the header's x or the Preview toggle. Visibility and width are saved. The preview's page mode is saved separately from fullscreen.
