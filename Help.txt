Lilium 操作ヘルプ

以下のキー・マウス操作は初期設定です。設定の「キー設定」で変更でき、「適用」で全ウィンドウへ即反映します。各操作の現在の割り当ては設定画面で確認してください。未適用の編集は有効になりません。

一覧
通常フォルダーの表紙は、画像・ZIP／CBZ・PDFを直下→子→孫の順で探します。同じ深さではフォルダー名、各フォルダー内ではファイル名の自然順で先頭を選びます。最大256フォルダーまで探索し、隠し・システム項目とリンク先は除外します。
PDFを開くと、そのPDFのページを読書画面で表示します。先頭ページが表紙サムネイルになります。開くためにパスワードが必要なPDF、ZIP・CBZ内のPDF、PDFのページ一覧には対応していません。
ZIP・CBZを開くと、内部の画像・フォルダー・その他のファイルを表示できます。対応画像以外のファイルは表示のみで、開くことはできません。上の階層・戻る・進むで通常のフォルダーと同様に移動します。
圧縮ファイルの内部は読み取り専用です。内部の項目のコピー・移動・削除・評価・Undo、クイックアクセス登録には対応していません。圧縮ファイル自体は通常のファイルとして操作できます。
パスワード付きZIP・CBZは開けません。RAR・7zには対応していません。
Enter / Space : 1項目選択時に開く
Backspace / マウス戻る : 戻る（履歴）
マウス進む : 進む（履歴）
Esc : 上の階層へ移動
Ctrl+C / Ctrl+X / Ctrl+V : コピー / 切り取り / 貼りつけ
Ctrl+V はフォルダー1つを選択中ならその中、それ以外は現在の場所へ。
ツリーにフォーカスがあってもCtrl+Vは右側の一覧を基準にします。
文字入力欄では通常の文字の貼り付けになります。
F2 : 名前の変更
Del : ごみ箱へ削除
Ctrl+Shift+N : 新規フォルダー
Ctrl+Z : 直前のファイル操作の取り消し（上書き操作は対象外）
Ctrl+A : すべて選択
F5 : 更新
0～5 : 選択した項目の評価を変更（名前に評価情報を付けます）
Ctrl / Shift + クリック : 複数選択
空白を左クリック : 選択解除
ドラッグ : 同じドライブへは移動、異なるドライブへはコピー。Ctrlを押しながらドラッグ : コピー、Shiftを押しながらドラッグ : 移動
設定の「操作設定」→「ファイル操作」で「常に移動」を有効にすると、ドライブにかかわらず移動し、Ctrlを押している間だけコピーします。

読書画面
PDFでも以下の読書操作が使えます。ページ順はPDFの順序に従い、横長の見開きページは1ページとして表示します。PDFの編集・文字検索・印刷には対応していません。
開いた時点で、呼び出し元の一覧ウィンドウと同じモニターに全画面表示します。
画面下10％へカーソルを移動すると操作パネルを表示します。パネルから離れると隠れます。
パネルから末尾・先頭への移動、次・前へのページ送り、読書画面を閉じる操作ができます。
一枚表示・二枚表示、とじ方向も切り替えられます。とじ方向は読書画面を開いた元の一覧にも反映し、保存します。
右とじ：左クリックで次、右クリックで前
左とじ：右クリックで次、左クリックで前
ホイール下：次、上：前
Esc / Backspace / マウス戻る：読書画面を閉じる
左右矢印 / A・D：閉じ方向に沿ってページ送り
下矢印 / S：1ページ先、上矢印 / W：1ページ前
Space：次のページ
1 / 2：1枚表示 / 2枚表示

ダイアログ
Enter：主操作（作成・変更・続行・保存など）
Esc：キャンセル／閉じる
処理中のEscは処理のキャンセルを要求し、安全な停止を待ちます。
選択リストを開いている場合は、先にその選択操作が行われます。

設定
表示設定の「表示言語」で日本語・Englishを選べます。選択は即座に保存され、すべてのLiliumウィンドウを閉じて起動し直した後に反映されます。
左下の「設定」からキャッシュ設定とこのヘルプを開けます。
設定は専用ウィンドウで開き、同じアプリ内では1つだけ表示します。
最後の一覧ウィンドウを閉じると設定も閉じます。キャッシュ容量はスライダーで選び「適用」で保存します。全削除は確認後に実行します。
キャッシュはJPEG品質70・最大300×400、S/M/L共通です。
容量上限500 MB～5 GB。超過時は古い利用日時順に90％まで整理。
フォルダーの「キャッシュのクリア」は直下の画像の再生成用です。
元画像・評価・設定は消しません。サブフォルダーの画像は対象外です。
現在の一覧は更新して再生成し、ほかの場所は次に開いたときに再生成します。
